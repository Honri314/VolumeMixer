VolumeMixer
macOS 앱별 볼륨 믹서

Windows처럼 출력 중인 앱마다 소리 크기를 따로 조절합니다. 커널 확장도, 가상 오디오 드라이버 설치도 없습니다. 완전 무료 오픈 스타일, macOS 14.4+ Process Tap 기반.

다운로드 하러 가기 디스코드에서 소식 받기
ver 0.1.0 · macOS 14.4 이상 · Apple Silicon (arm64)

주요 기능

메뉴바에서 항상 접근, 제어센터처럼 각 앱의 긴 볼륨 바를 따로 조절합니다

1 메뉴바 위젯

메뉴바에서 바로 팝오버로 열며, 출력 중인 앱 목록이 자동 갱신됩니다.

2 제어센터 스타일 바

세로로 긴 캡슐형 볼륨 바를 드래그해 앱마다 따로 조절. 퍼센트가 실시간 표시됩니다.

3 원본 스트림 보존

볼륨 100%일 때는 tap 없이 충실하게 원본 출력. 조절 중일 때만 tap을 열어 처리합니다.

4 드라이버 설치 불필요

kext·BlackHole 같은 가상 드라이버 없이 Apple Core Audio Process Tap만 사용합니다.

시스템 요구사항

  • macOS 14.4 이상 (Apple Process Tap API 요구)
  • Apple Silicon (M1/M2/M3/M4) Mac
  • 첫 실행 시 시스템 설정 > 개인정보보호 > 오디오 녹음 권한을 승인해야 앱별 조절이 동작합니다
  • Gatekeeper 닫힘 안내 시: 마우스 우클릭 > 열기로 우회 가능 (ad-hoc 서명 앱)

설치 방법

3단계로 끝납니다

1
DMG를 열고 VolumeMixer.app를 Applications 폴더로 옮깁니다.
2
앱을 실행하면 메뉴바에 슬라이더 아이콘이 나타납니다. (Dock 아이콘은 없습니다)
3
아이콘 클릭 후, 소리를 내고 있는 앱의 세로 볼륨 바를 내려서 조절합니다.
